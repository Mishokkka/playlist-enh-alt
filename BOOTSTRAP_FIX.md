# Критическое исправление запуска — 1.3.12

3 ноября 2026 года, Foundry VTT 13.351.

## Причина отказа кнопок и воспроизведения

Ошибка пользователя `You may only push instances of Playlist to the Playlists collection` вызвана предыдущим патчем модуля. Он заменял `CONFIG.Playlist.documentClass` и `CONFIG.PlaylistSound.documentClass` в hook `setup`.

Фактический порядок Foundry:

1. `Game.initialize()` вызывает `init`.
2. `Game.setupGame()` вызывает `initializeDocuments()`: коллекции и существующие документы создаются с текущими классами.
3. Затем вызывается `setup`.
4. При обновлении клиентский backend получает уже существующий документ и вызывает `collection.set()`.
5. Настоящая `DocumentCollection.set()` сравнивает документ с классом из текущего CONFIG через `instanceof`. После поздней замены класса проверка проваливается.

Из-за этого ломались любые обновления существующих плейлистов. Загрузка нового трека могла работать, поскольку новый документ создавался уже с заменённым классом. Ошибка возникает после ответа сервера, поэтому предшествующие нажатия могли успеть сохранить состояние воспроизведения; после перезагрузки проверьте Currently Playing.

Проверенные исходники установки: `client/game.mjs`, `client/documents/abstract/document-collection.mjs`, `client/data/client-backend.mjs`.

## Исправление

Оба подкласса регистрируются в `init`, до создания коллекций и вложенных документов. В `setup` остаются обработчики событий; конструкторы в этой фазе не меняются. Установщики дополнительно отказываются менять классы, если `game._documentsReady` уже установлен. Проверка типов коллекции сохранена.

Для применения требуется **полная перезагрузка каждого клиента**: `Ctrl+Shift+R` или закрытие и повторное открытие клиента Foundry. Открытые экземпляры 1.3.11 сохраняют старые классы в памяти до перезагрузки.

## Проверка и пределы

Новый `tests/bootstrap.test.mjs` загружает настоящие `Collection`, `DocumentCollection`, `WorldCollection`, `Playlists` и полный `ClientDatabaseBackend`, включая приватный обработчик обновления. Вспомогательная часть UI коллекции, базовая модель данных, устройство и транспорт моделируются; строгий `instanceof` и возврат документа в коллекцию исполняются штатным кодом.

Прежние тесты заменяли коллекцию мира обычным Map и пропускали этот шаг. Поэтому прохождение 106 прежних проверок не было доказательством корректного запуска модуля в мире.

Шесть новых сценариев проверяют транспортные команды существующего плейлиста, обновление вложенного звука, совместимость существующих и новых документов, выключенную оптимизацию таймеров, последующий init-подкласс другого модуля и отказ поздних установщиков. На сохранённой 1.3.11 все шесть падают, включая точную ошибку со скриншота; на 1.3.12 все шесть проходят. Полный прогон семи файлов — **112 успешных проверок**.

```powershell
node --test --test-isolation=none tests/bootstrap.test.mjs
```

Для запуска против старой копии задайте `PE_BOOT_TARGET` на каталог 1.3.11. Требуется локальная установка Foundry; путь переопределяется через `FOUNDRY_V13_APP`. Исходники движка не включены в модуль.

Копия 1.3.11, SHA-256 и журналы сохранены в `playlist-enchantment-audit/hotfix-1.3.12` внутри каталога аудита Codex. Этот прогон не заменяет прослушивание аудио и измерение FPS работающего мира.
